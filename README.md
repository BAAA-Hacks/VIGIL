# VIGIL

Visual Intelligence & Geolocation for Incident Location.

The UI/UX ground-station app lives in [`ground-station/`](./ground-station/). Its source, dependencies, configuration, and tests are contained there so other workstreams can use separate folders.

## Run the dashboard

```powershell
cd ground-station
npm install
npm run dev
```

Open http://127.0.0.1:5173/.

See [the app README](./ground-station/README.md) for architecture, integration, and verification instructions.
